پیش‌نیاز: پایتون نصب باشه

توی ترمینال (cmd یا PowerShell) این دستور رو بزن:

python --version

اگه نسخه‌ای مثل Python 3.12.0 نشون داد، یعنی نصبه. اگه نه، از python.org نصبش کن — موقع نصب حتماً تیک Add Python to PATH رو بزن.

STEP 01

ساخت پوشه‌ی پروژه

mkdir django_project
cd django_project

این یه پوشه‌ی خالیه که از این به بعد همه‌چیز داخلش ساخته می‌شه.

STEP 02

ساخت محیط مجازی (venv)

python -m venv venv

چه اتفاقی افتاد؟ یه پوشه به اسم venv ساخته شد؛ یه کپی مجزا از پایتون. هر پکیجی که از این به بعد نصب کنی، فقط داخل همین پوشه می‌ره، نه روی کل سیستم.

venv/ ├── Scripts/ (ویندوز) یا bin/ (لینوکس/مک) → فایل‌های فعال‌سازی و pip ├── Lib/ → پکیج‌های نصب‌شده اینجا می‌رن └── pyvenv.cfg
STEP 03

فعال‌سازی venv

ویندوز (PowerShell)

venv\Scripts\Activate.ps1

ویندوز (cmd)

venv\Scripts\activate.bat

لینوکس / مک

source venv/bin/activate

بعد از این دستور، باید (venv) رو کنار خط فرمانت ببینی. یعنی از الان python و pip از داخل همین پوشه اجرا می‌شن، نه از سیستم.

⚠ خطای اجرای اسکریپت در PowerShell؟ این دستور رو یک‌بار بزن و دوباره امتحان کن: 
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
STEP 04

نصب جنگو

pip install django

برای اینکه بعداً دقیقاً بدونی چه نسخه‌ای نصب کردی:

pip freeze > requirements.txt

این دستور فایل requirements.txt رو با محتوایی شبیه این می‌سازه:

asgiref==3.12.1
Django==6.1.1
sqlparse==0.6.0
STEP 05

ساخت پروژه‌ی جنگو

django-admin startproject mysite .

نقطه‌ی آخر (.) مهمه — یعنی «همین‌جا بساز، پوشه‌ی تو در تو نساز».

django_project/ ├── manage.py └── mysite/ ├── __init__.py ├── settings.py ├── urls.py ├── asgi.py └── wsgi.py
فایلکارش چیه
manage.pyابزار خط‌فرمان جنگو — همه‌ی دستورات با این اجرا می‌شن
settings.pyتنظیمات کل پروژه: دیتابیس، زبان، اپ‌های نصب‌شده
urls.pyنقشه‌ی مسیرها — هر آدرس به کدوم بخش کد وصله
wsgi.py / asgi.pyمربوط به اجرای سرور در پروداکشن — فعلاً دست نزن
STEP 06

ساخت اپلیکیشن (app)

هر پروژه‌ی جنگو از چند «اپ» کوچیک تشکیل می‌شه (یکی برای وبلاگ، یکی برای فروشگاه...). بیا اولین اپ رو بسازیم:

python manage.py startapp core
core/ ├── migrations/ │ └── __init__.py ├── __init__.py ├── admin.py ├── apps.py ├── models.py ├── tests.py └── views.py
فایلکارش چیه
models.pyتعریف جدول‌های دیتابیس (مدل «مقاله»، «محصول» و...)
views.pyمنطق هر صفحه — چه دیتایی نشون داده بشه
admin.pyثبت مدل‌ها توی پنل مدیریت
migrations/تاریخچه‌ی تغییرات دیتابیس
tests.pyتست‌های خودکار
STEP 07

معرفی اپ به پروژه

فایل mysite/settings.py رو باز کن و اپ رو به INSTALLED_APPS اضافه کن:

INSTALLED_APPS = [
    'django.contrib.admin',
    'django.contrib.auth',
    'django.contrib.contenttypes',
    'django.contrib.sessions',
    'django.contrib.messages',
    'django.contrib.staticfiles',
    'core',   # ← این خط رو اضافه کن
]
STEP 08

ساخت یه صفحه (view + template)

۸.۱ — ویو رو بنویس

توی core/views.py:

from django.shortcuts import render

def home(request):
    return render(request, "core/home.html")

۸.۲ — پوشه‌ی قالب (template) بساز

mkdir core\templates\core     # ویندوز
mkdir -p core/templates/core  # لینوکس/مک

فایل core/templates/core/home.html رو بساز:

<!DOCTYPE html>
<html lang="fa" dir="rtl">
<head><meta charset="UTF-8"><title>سایت من</title></head>
<body>
    <h1>سلام دنیا! جنگو کار می‌کنه 🎉</h1>
</body>
</html>

۸.۳ — مسیر رو وصل کن

توی mysite/urls.py:

from django.contrib import admin
from django.urls import path
from core.views import home

urlpatterns = [
    path('admin/', admin.site.urls),
    path('', home, name='home'),
]
STEP 09

ساخت دیتابیس (migrate)

python manage.py migrate

این دستور جدول‌های پیش‌فرض جنگو (کاربران، سشن‌ها و...) رو توی فایل db.sqlite3 می‌سازه.

STEP 10

اجرای سرور

python manage.py runserver

حالا برو به مرورگر: http://127.0.0.1:8000/

STEP 11

ساخت کاربر ادمین (اختیاری)

python manage.py createsuperuser

یوزرنیم/ایمیل/پسورد رو وارد کن، بعد برو به http://127.0.0.1:8000/admin/

ساختار نهایی پوشه‌ها

django_project/ ├── venv/ ← محیط مجازی — هیچ‌وقت دستی داخلش دست نزن ├── db.sqlite3 ← دیتابیس (بعد از migrate ساخته می‌شه) ├── manage.py ├── requirements.txt ├── mysite/ ← تنظیمات اصلی پروژه │ ├── settings.py │ ├── urls.py │ ├── wsgi.py │ └── asgi.py └── core/ ← اپلیکیشن ├── models.py ├── views.py ├── admin.py ├── migrations/ └── templates/core/home.html

خلاصه‌ی همه‌ی دستورات پشت‌سرهم

mkdir django_project
cd django_project
python -m venv venv
source venv/bin/activate        # یا venv\Scripts\activate در ویندوز
pip install django
pip freeze > requirements.txt
django-admin startproject mysite .
python manage.py startapp core
# اضافه کردن 'core' به INSTALLED_APPS در settings.py
# نوشتن view، template و url طبق مرحله‌ی ۸
python manage.py migrate
python manage.py runserver

هر بار که دوباره خواستی روی پروژه کار کنی

نه ساخت دوباره‌ی venv، نه نصب دوباره‌ی جنگو — فقط این دوتا کافیه:

  • فعال‌سازی venv: source venv/bin/activate (یا venv\Scripts\activate)
  • اجرای سرور: python manage.py runserver

همین بود 🎉

حالا یه پروژه‌ی جنگوی کامل و در حال اجرا داری.
