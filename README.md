# 🎮 Combat Arena

بازی تیراندازی سه‌بعدی اول‌شخص، **چندنفره و Real-Time**، دو تیمه (🟦 یار در برابر 🟥 دشمن) — ساخته‌شده با **Django + Django Channels (WebSocket)** برای بک‌اند و **Three.js** برای گرافیک سه‌بعدی. طراحی‌شده برای بازی با دوستان روی یه شبکه‌ی وای‌فای مشترک، بدون نیاز به هیچ سرور خارجی یا اکانتی.

---

## ✨ امکانات

- 🔫 **تیراندازی اول‌شخص سه‌بعدی واقعی** با Three.js — نور و سایه‌ی داینامیک، آسمون روز، ابر، درخت، زمین بزرگ با بافت واقعی
- 🧍 **کاراکترهای انسانی ریگ‌شده و انیمیشن‌دار** (نه مکعب و استوانه) با انیمیشن راه‌رفتن واقعی
- 🌐 **چندنفره‌ی زنده روی WebSocket** — بدون هیچ Bot یا NPC؛ فقط بازیکن‌های واقعی
- 🚪 **سیستم Room با کد اتاق مشترک** — لابی Real-Time، دیدن ورود/خروج بازیکنان بدون Refresh
- 🟦🟥 **سیستم دو تیم** با انتخاب زنده و شمارش اعضا
- 🔁 **سیستم Round**: وقتی یه تیم کامل حذف بشه، تیم مقابل برنده‌ی همون دور می‌شه؛ با دکمه‌ی «بازی بعدی» توی همون اتاق دوباره شروع می‌کنید
- 🎯 نمایش تفنگ روی دست بقیه‌ی بازیکنان + افکت شلیک و برخورد واقعی برای همه
- 🔊 سیستم صدای کامل (شلیک، اصابت، صدمه، شارژ مجدد، قدم، مرگ، شروع/پایان دور) — کاملاً سینتتیک، بدون فایل صوتی خارجی
- ⏸️ منوی Pause با `ESC` که هیچ‌وقت از بازی یا اتاقت بیرونت نمی‌کنه
- 🔄 **خودترمیم‌شونده در برابر قطعی شبکه**: اتصال مجدد خودکار + همگام‌سازی دوره‌ای که هر بازیکنی که گم بشه رو خودکار برمی‌گردونه

## 🧱 تکنولوژی‌ها

| بخش | تکنولوژی |
|---|---|
| بک‌اند | Django 6.1 |
| ارتباط زنده | Django Channels + Daphne (ASGI/WebSocket) |
| فرانت‌اند بازی | Three.js (r128) — بدون فریم‌ورک اضافه |
| مدل کاراکتر | مدل رسمی و انیمیشن‌دار `Soldier.glb` از خودِ پروژه‌ی Three.js |
| صدا | Web Audio API (سینتتیک، بدون asset خارجی) |
| دیتابیس | SQLite (پیش‌فرض جنگو) |

## 🚀 راه‌اندازی سریع

```bash
git clone <این-ریپو>
cd django_project

python -m venv venv
source venv/bin/activate        # ویندوز: venv\Scripts\activate

pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

برو به `http://127.0.0.1:8000/` — از اونجا به صفحه‌ی راهنما (`/guide/`) و بازی (`/game/`) لینک هست.

## 🕹️ بازی چندنفره روی وای‌فای مشترک

برای اینکه دوستانت هم بتونن وصل بشن، سرور باید روی شبکه در دسترس باشه:

```bash
python manage.py runserver 0.0.0.0:8000
```

سپس آی‌پی داخلی خودت رو پیدا کن (`ipconfig` در ویندوز یا `ifconfig`/`ip addr` در مک/لینوکس) و:

- خودت برو به `http://127.0.0.1:8000/game/`
- دوستانت (روی همون وای‌فای) برن به `http://<آی‌پی-تو>:8000/game/`

توی صفحه‌ی بازی، هرکس یه اسم و **یه کد اتاق مشترک** (مثلاً `A7K29`) وارد می‌کنه — همه‌ای که کد یکسان بزنن، مستقیم وارد همون Lobby می‌شن. بعد هرکس تیم 🟦 یار یا 🟥 دشمن رو انتخاب می‌کنه و هرکسی می‌تونه دکمه‌ی «شروع بازی» رو بزنه.

## ⚠️ محدودیت‌های شناخته‌شده

- چندنفره فقط داخل یه **شبکه‌ی محلی (LAN)** کار می‌کنه. برای بازی با کسی در شهر/خونه‌ی دیگه، باید پروژه روی یه سرور اینترنتی هاست بشه.
- تشخیص اصابت گلوله سمت مرورگرِ تیرانداز انجام می‌شه؛ سرور فقط اعتبارسنجی می‌کنه که شلیک بین دو تیم مختلف و دو بازیکن زنده بوده. برای بازی دوستانه کافیه، ولی جلوی تقلب حرفه‌ای (دستکاری کد جاوااسکریپت) رو صددرصد نمی‌گیره.
- وضعیت Room/بازیکنان در حافظه‌ی پردازش سرور نگه‌داری می‌شه (بدون Redis)؛ یعنی با ری‌استارت سرور، اتاق‌های باز از بین می‌رن — برای یه بازی خانگی مشکلی نیست.
